# Руководство по запуску продакшн-сервера DuoWindo6601 (server.js) 🌐

В проект DuoWindo6601 успешно добавлен собственный легковесный продакшн-сервер на чистом Node.js (`server.js`). Он оптимизирован для быстрой загрузки, безопасного обслуживания статических ресурсов (`index.html`, CSS, JS, изображения, аудио) и корректной поддержки маршрутизации одностраничных приложений (SPA/React).

---

## 🚀 Быстрый старт (Запуск в продакшене)

Чтобы запустить собранное приложение в режиме продакшена, выполните три простые команды:

### Шаг 1: Установка зависимостей
Убедитесь, что все необходимые модули загружены:
```bash
npm install
```

### Шаг 2: Компиляция статических ресурсов (Сборка)
Соберите веб-приложение. Это сгенерирует оптимизированные минифицированные файлы в папку `dist/`:
```bash
npm run build
```

### Шаг 3: Запуск сервера
Запустите Node.js сервер, который развернёт приложение на хосте `0.0.0.0` (порт `3000`):
```bash
npm start
```

После этого приложение будет доступно по адресу: **http://localhost:3000** 🚀

---

## 🛠️ Режим разработки (без компиляции ресурсов)

Для внесения изменений в код и мгновенного обновления интерфейса в реальном времени (HMR) запускайте локальный сервер разработки Vite:
```bash
npm run dev
```

## 🧠 Ключевые возможности и архитектура server.js

Продакшн-сервер в файле `server.js` решает несколько важных задач:

1. **Защита от Directory Traversal (Уязвимость обхода каталога):**
   Код строго проверяет пути запрашиваемых файлов и не позволяет злоумышленникам прочитать файлы за пределами директории `dist/`.
2. **SPA Маршрутизация (Fallback):**
   Если пользователь обновляет страницу на внутреннем URL-адресе (например, `/profile` или `/chess`), сервер не выдаёт ошибку `404 Not Found`. Вместо этого он автоматически отправляет `index.html`, позволяя React-роутеру корректно обработать адрес на стороне клиента.
3. **Обработка URL-декодирования и параметров:**
   Сервер очищает GET-параметры из URL и корректно декодирует URL-кодированные символы (например, пробелы или кириллицу).
4. **Поддержка современных MIME-типов:**
   Сервер полноценно поддерживает все типы ресурсов: модули Javascript (`.js`, `.mjs`), стили (`.css`), изображения (`.svg`, `.png`, `.jpg`), а также аудиозаписи (`.mp3`, `.wav`) для звуковых эффектов.
